1這個系統在做什麼

科基金每個月有一筆錢入帳，科內拿去買東西、辦活動。實務上常常是某位醫師先自己墊錢，之後再跟醫院請款拿回來。

這個系統要解決兩件事：

  • 錢花到哪裡去了 — 每筆支出誰花的、買什麼、多少錢，全科都看得到
  • 墊錢的人有沒有拿回來 — 這是重點。系統會一直盯著還沒回到代墊者手上的錢，直到對方親自簽名確認收到為止
所有資料即時同步到雲端，手機、電腦、平板打開看到的都是同一份。任何人改了，其他人畫面會馬上跟著更新。

2裝到手機當 App 用

不用去 App Store 下載，用瀏覽器加到主畫面就有獨立圖示，開起來跟一般 App 一樣（沒有網址列）。

iPhone / iPad（要用 Safari）

  1. 用 Safari 打開系統網址（用 Chrome 開不會有這個選項）
  2. 點畫面下方中間的「分享」鈕（方框加向上箭頭）
  3. 往下滑，選「加入主畫面」
  4. 右上角「新增」，主畫面就出現金幣圖示了

Android（Chrome）

  1. 用 Chrome 打開系統網址
  2. 點右上角三個點
  3. 選「加到主畫面」或「安裝應用程式」，確定
裝好之後沒網路也打得開，會顯示最後一次同步到的資料；等有網路時再自動同步。
但是發票照片和簽名需要連線才看得到，因為那些檔案存在雲端沒有放在手機裡。

3第一次使用要設定的三件事

到最右邊的「設定」分頁：

① 我是誰

選你自己的名字。之後你新增支出時，系統會自動把「代墊者」預設成你，並記錄是你填的表。這個設定只存在你這台裝置，每個人各自設定一次就好。

② 成員名單

把科內醫師的名字加進去，之後「代墊者」下拉選單才有得選。

名單只存在雲端資料庫，不會寫進網站的程式碼裡。

③ 期初結餘

如果開始用這個系統之前科基金已經有一筆餘額，填在這裡，總覽的「累計結餘」才會對。從零開始的話就留 0。

4記一筆支出（含拍發票）

在「總覽」或「支出明細」按 ＋ 新增：

欄位說明
日期實際花錢那天。不能填未來的日期，系統會擋下來。
金額實付金額。
支出用途寫清楚一點，例如「科務會議便當 30 份」比「餐費」有用。
代墊者誰先掏錢出來的。這欄決定之後錢要還給誰，一定要填對。
發票／收據照片見下方。
備註發票號碼、參加人員之類。

拍發票

  • 按「📷 拍照」→ 手機直接開相機，拍完就好
  • 按「🖼️ 選照片」→ 從相簿挑一張已經拍好的

照片會自動壓縮（通常從好幾 MB 縮到 50 KB 左右），不用擔心佔空間或上傳很慢。存好之後，明細表的「發票」欄會出現 🧾，點下去可以放大看。

要換照片直接再拍一次或再選一次就會蓋掉；要拿掉按「移除」再儲存。

5兩種狀態：請款中／已到帳

請款中 → 簽名 → 已到帳
狀態意思
請款中錢還是代墊者自己出的，還沒回到他手上。系統會一直把這筆算進「代墊者還沒拿到」。
已到帳代墊者確認實際拿到錢了，而且已經簽名存證。這筆才算結清。

在明細表或結算頁直接點狀態標籤就能切換。

「已到帳」一定要簽名，沒有例外。從「請款中」切到「已到帳」時系統一定會跳出簽名板，沒簽就不給過。編輯視窗裡的狀態是唯讀的，看得到但改不了，就是為了防止有人不簽名直接標成已到帳。
標錯了要退回？點「已到帳」的標籤會跳出嚴格確認視窗：顯示這筆的金額、代墊者、原簽收人與時間，你必須勾選「我確認○○○尚未收到這筆 NT$X」才能按下退回。退回後簽名會被刪除且無法復原。
如果這張簽名還涵蓋其他筆，視窗會提醒你，其他筆不受影響。

6簽名確認收款

簽名板會顯示誰、收多少、包含哪幾筆，請代墊者本人確認金額無誤後，用手指或觸控筆在框裡直接簽。

  1. 核對上方的姓名、金額、明細
  2. 在框內簽名（簽壞了按「清除」重簽）
  3. 按「確認已收款」

簽完之後那幾筆會一起變成已到帳，明細表的「簽收」欄出現 ✍️，點下去可以看到簽名圖、簽收人、金額和時間。

一次簽多筆：在「請款結算」頁按某人的「簽名確認已到帳」，他所有請款中的項目會併成一筆一起簽，不用一筆一筆簽。這幾筆共用同一張簽名。
簽名需要連線才能存檔。沒網路的時候會提示你，等有網路再簽。

7請款結算：確保每個人都拿到錢

這頁是整個系統的重點。它把所有支出依代墊者分組，一眼看出誰還沒拿到錢。

每個人的區塊會顯示：

  • 請款中 — 他還沒拿回來的總額（橘色），下面列出是哪幾筆
  • 已到帳 — 已經還給他、有簽名為證的總額（綠色）
  • 累計代墊 — 他總共為科裡墊過多少錢

還沒結清的人排在最前面。全部結清的人會標上已結清。

上方可以切「全部期間」或「僅本檢視月份」。建議用「全部期間」，才不會漏掉前幾個月卡住沒處理的舊帳。

總覽頁最上面那張紅框卡片「代墊者還沒拿到」，就是這頁的總和。這個數字應該要定期歸零。

8每月入帳與結餘

科基金每個月撥下來的錢，到「設定 → 每月入帳」登錄：選月份、填金額、可以加備註，按儲存。當月沒有入帳就填 0 或不要登錄。

登錄之後總覽頁就會算出：

  • 目前累計結餘 ＝ 期初結餘 ＋ 全部入帳 －全部支出
  • 本月收支 ＝ 當月入帳 －當月支出（負數表示當月超支，動用到以前的結餘）

「統計」分頁可以看每月收支長條圖，以及每個人累計代墊多少、還有多少沒拿到。

9匯出 PDF、CSV、備份

匯出 PDF（只有電腦版有）

「支出明細」頁按 🖨️ 匯出 PDF，會產生一份正式報表：標題、期間、收支摘要、支出明細表、各代墊者結算表，最下面有領款簽章欄和經辦人／科主任／會計的簽名欄，可以直接印出來當核銷附件。

  1. 按「🖨️ 匯出 PDF」，瀏覽器會跳出列印視窗
  2. 「目的地」選「另存為 PDF」
  3. 按儲存

報表範圍跟著你目前的篩選走 — 想印單月就先在上面選那個月。設定頁的「匯出全部 PDF」則是不管篩選全部印出來。

手機上不會看到這個按鈕，因為手機列印排版不好控制。要出報表請用電腦。

其他匯出

  • 匯出 CSV（支出明細頁）— 匯出目前篩選的結果，Excel 直接開得起來，含日期、用途、金額、代墊者、狀態、有無發票、簽收人與時間
  • 匯出全部 CSV（設定頁）— 不管篩選，全部倒出來，適合年度結算
  • 備份 JSON（設定頁）— 完整帳目備份檔，建議每季存一份
  • 還原 JSON — 用備份檔覆蓋目前所有資料
還原會覆蓋掉雲端上所有人的資料，不是只有你這台。除非真的出事，不然不要用。

註：CSV 和 JSON 不包含發票照片與簽名圖，那些留在雲端。

10常見問題

兩個人同時在改，會不會互相蓋掉？

不會。系統是一筆一筆分開存的，你改你那筆、他改他那筆，互不影響。

誰看得到這些資料？

知道網址的人都看得到，沒有設密碼。裡面有醫師姓名和金額，網址請不要外流。要加密碼保護隨時可以加回來。

不小心刪掉一筆怎麼辦？

刪除無法復原，雲端上也會一起消失。所以刪除前會跳出確認。真的刪錯了，只能用備份 JSON 還原，或手動重新輸入。

照片上傳失敗？

檢查右上角是不是「☁️ 已連線」。如果顯示未連線，按旁邊的「同步」重新連。照片一定要連線才能上傳。

手機上看不到表格的某些欄位？

螢幕窄的時候明細會自動變成卡片式，資訊都在，只是排法不同。橫著拿手機或用平板／電腦會看到完整表格。

為什麼不能自己把狀態改成「已到帳」？

因為「已到帳」代表錢真的回到代墊者手上，這件事只有代墊者本人能確認。所以一定要他簽名，系統才承認。這是整套系統存在的理由。

日期為什麼不能選未來？

科基金是實支實付，還沒發生的支出不該入帳。要預估的花費請等實際付款後再登錄。
